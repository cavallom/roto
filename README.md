# Roto

Roto is a tool created specifically for the DAW Renoise and designed for live performances. It is a random note generator—unconstrained by musical scales or harmonic logic—that uses six tracks, each controlled by its own dedicated knob. Roto can be used as a genuine musical instrument, employing knobs instead of strings and frets to generate ephemeral musical phrases—with their shape, dynamics, and breath all intrinsically linked to the musician’s touch and sensitivity. The live performance that is captured can, however, also be render as a song.

## Install

To install the tool, download the compressed file and drag it directly onto the Renoise interface. For further details on how to install tools, please refer to the Renoise guide.

## Load Roto Tool
The Roto tool can be launched by selecting the Tools/Roto menu item within the Renoise application.
The corresponding track managed by Roto is created automatically, if it does not already exist, the first time Roto is launched.

## Activation

The generation and writing of notes is triggered only if playback is initiated using the [Start] button in the Roto tool.

## Note generation

With each movement of the knob, the range for note randomization is narrowed; it begins from the note selected at the end of the rotation, extending one octave above and one octave below. From the resulting set of notes (including semitones), a note is chosen at random and written into the current step of the active sequence for the corresponding track. To achieve a cleaner sound, the lowest and highest octaves are removed from the set of selectable notes, thereby avoiding excessive bass and treble.

### Volume

If enabled the [*vol] checkbox, this adds a random value for the volume to the note generated and written in the current sequence. Enabling or disabling this feature determines whether or not the volume column is displayed in the track.

### Pan

If enabled the [*pan] checkbox, this adds a random value for the panning to the note generated and written in the current sequence. Enabling or disabling this feature determines whether or not the panning column is displayed in the track.

### Delay

If enabled the [*dly] checkbox, this adds a random value for the delay to the note generated and written in the current sequence. Enabling or disabling this feature determines whether or not the delay column is displayed in the track.

## Clean Sequence

When Roto is running, set the knob to 0 to clear all sequences in a track.

## Instruments

The data stream generated by Roto tracks can be mapped to hardware synths, VSTs, or Renoise instruments, with their envelopes adjusted to respond to the touch sensitivity of the knobs and the dynamics of the musical piece being performed.

## MIDI map
Knob can be mapped to a MIDI controller for greater versatility and expressiveness of the Roto tool.
